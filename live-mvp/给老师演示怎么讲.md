# 两分钟演示讲稿

公开包只含代码和说明；使用前需按 README 配置已有本机环境、私有模型和数据。

1. 打开 `run.cmd`。说明：“这是基于 ESP32-C6 和 ESPectre 的 Wi-Fi CSI 实验原型，用来研究人员存在检测和风扇等干扰。”
2. 如果 ESP32 已连接同一局域网，输入当前 IP 并点击“开始接入”。等待显示包数、CSI 曲线和“有人／无人／未知”；指出模型是实验性判断，可能误报。设备未连接时如实说明，进入文件回放演示，不声称实时连接成功。
3. 停止实时接入，查看页面记录的流关闭与恢复状态。恢复到原模式不等于已独立确认普通运动检测正常。
4. 点击“文件回放与运动对照”，选择场景并回放。指出采集时记录的场景与模型判断分开展示，可以下载 CSV／JSON。
5. 看默认的第 5 批 S4：“这段录制是无人、风扇开启，但模型把所有窗口判断为有人，说明现阶段仍不可靠。”

## 简短英文版

“This is our local Wi-Fi CSI research prototype. An ESP32-C6 running ESPectre can stream CSI to the computer, where an experimental model displays present, empty, or unknown. We can also replay recorded trials and compare two motion methods. In this empty-room recording, the model incorrectly reports a person. Reliable presence detection and interference resistance remain to be validated.”

## 老师可能会问

- **IDLE 是否等于无人？** 不等于。IDLE 只表示运动方法在该窗口没有检测到运动，静坐的人也可能对应 IDLE。
- **为什么会有 UNKNOWN？** 窗口质量不够，或人员模型得分落在不确定区域时，保留未知。
- **237 个窗口是不是 237 次实验？** 不是。它们来自同一次录制，时间上相互重叠。
- **模型是否已经解决风扇干扰？** 没有。当前无人风扇场景存在明显误报，运动滞回对照也没有实现预期的误报降低。
- **这个页面是实时检测吗？** 实时页有设备接入功能；是否在演示现场真正接通，要看连接状态和包数。文件回放页使用已保存的真实 CSI，两者不能混淆。
