# 实时演示：先这样操作

公开包只含代码和说明；使用前需按 README 配置已有本机环境、私有模型和数据。

1. 双击 `run.cmd`，等待浏览器打开。电脑与 ESP32 要连到能互相访问的同一局域网，先关闭其他原始 CSI 采集程序和可视化页面。
2. 在页面填写 ESP32 当前的 IP 地址。`192.168.1.50` 只是示例；可在路由器的已连接设备列表或 ESPectre 工具中查询。
3. 检查地点标记：当前真实模型针对 418 采集记录训练；实际地点不同时请填写实际值，输出会保留未知。系统不能自动验证地点。
4. 设置接入时长（3–600 秒，默认 60 秒），点击“开始接入”。成功后会显示连接状态、接收包数、近期 CSI 变化、窗口质量和实验性“有人／无人／未知”。到时自动停止，也可点击“停止接入”。
5. 停止后查看“原始流”和“恢复结果”。如果恢复失败或未确认，请在 ESPectre 中核实；恢复的是接入前的流量模式，并不自动证明普通运动检测正常。

页面右上角的“文件回放与运动对照”保留了已有 26 份本机私有真实记录（此仓库不包含这些新文件），可在设备离线时使用并导出 CSV、JSON。实时接入只保留短滚动缓冲，不会生成带标签的正式采集文件。

文件回放默认展示第 5 批 S4：它是无人、风扇开的真实录制，但当前模型把所有窗口判断为有人。这个反例说明模型还不可靠；切换其他场景可以继续查看实际结果。

每个窗口为 1 秒且相互重叠，窗口数量不是独立实验次数。断线、停止、长时间无包、窗口不合格或得分不确定时显示“未知”；未知不能当作无人，运动方法的 IDLE 也不能当作无人。模型只是实验性判断，可能误报，不能用于自动控制。

本次软件使用现有 ESPectre 3.0.0 环境，没有重新安装。2026-11-05 检查时电脑在其他网段，上次的设备地址未响应；实时硬件连接、停止与恢复尚未在本次验证，模拟测试不代表真实设备已经接通。
