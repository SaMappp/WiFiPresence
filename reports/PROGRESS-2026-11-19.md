# WiFiPresence course project progress, 2026-11-19

The single-room, single-link ESP32-C6 demonstration is complete as a project milestone. The current local workbench uses a confirmed-empty reference and a continuous detection switch. The file-replay workflow retains the historical frozen model. Six-scene real-world validation of the current live detector and three independent team reproductions remain open.

- **Public pilot.** The eight public NPZ files matched their stored SHA-256 hashes. Six are scene pilots and two are excluded diagnostics. S1 and S4 failed official file admission. All six pilots retain their exclusion from formal fitting and testing. [Initial results](INITIAL-RESULTS.md)

All 26 selected recordings pass the stored official file-admission records. Scene labels came from the operator. Batch mapping, physical setup and action timing still need confirmation. Numerical files, private manifests, models, device information and source logs remain local.

## Live demonstration

The operator reported that the fan-on demonstration broadly matched the room conditions. The stored status readback showed 11,990 received packets, zero invalid packets, zero in-frame drops or backpressure, and confirmed raw-stream closure and restoration. The fresh 24-second reference had 93/93 eligible windows and 80% median slot coverage. These are transport and reference-quality results. The final single PRESENT window lacks an independently timed scene label. Recognition accuracy, false-negative rate and latency are unestablished for that run.

A separate timing probe achieved 93% median coverage and 93/93 eligible windows over its first 24 seconds. It tested sampling timing. A separate corridor observation combined reported empty-room conditions and activity outside the room. It showed mostly EMPTY with some UNKNOWN and PRESENT, and the device reported a transmission failure. The fan condition and independent action times were unconfirmed.

Continuous mode is controlled by one switch on the local page. It uses the same quality gates, one permitted reference retry and bounded transport recovery. The existing timed API remains available. The continuous lifecycle is software-tested with a simulated receiver. Long-running physical-device performance remains unverified.
