# Live MVP software publication, 2026-11-05

This update publishes code, web UI and documentation only. The owner chose to retain new CSI recordings, trained models and their metadata privately. Original public pilot files are preserved without change.

The local implementation adds a bounded ESPectre CSI stream, IP/room/duration controls, live packet and amplitude display, experimental occupancy output, stream cleanup and original traffic-mode readback, plus the previous file replay. The model has known serious empty-room false positives. UNKNOWN is retained for missing, stale, low-quality, uncertain or out-of-profile input and after stopping.

The local version passed 13 software checks with private recordings. Browser checks used a separate test-only simulated stream to verify start, dynamic output, stop, cleanup display and loss of service; these are not actual device observations. The pinned ESPectre imports loaded successfully. The previous device address was unreachable during read-only probes, so no new real device stream or restoration was validated in this session. Public tests use artificial transport fixtures and skip recorded-data checks if the private inputs are not configured.

Earlier real-data evaluation is retained in the private study archive. A notable counterexample is an empty/fan-on recording where all 237 overlapping windows were classified PRESENT. The baseline/hysteresis motion comparison also did not achieve the proposed fan false-positive reduction. The motion comparison was post-hoc, after classifier outcomes were known. Response latency and cross-room performance remain unmeasured.

GitHub Pages publishes only the project introduction. The live application must run on a local computer with the pinned backend and optional private model/data. This publication does not deploy a remote detector, open a cloud service or claim a reliable occupancy product.
