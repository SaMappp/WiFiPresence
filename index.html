WiFiPresenceGitHub 项目

把 Wi-Fi 信道变化
变成可检查的实验。

ESP32-C6 接收 CSI，电脑运行实验性模型，页面持续显示“有人／无人／未知”，并保留文件回放和运动方法对照。

这是公开项目入口。 GitHub Pages 只提供静态页面，不能运行 Python 或直接连接你的局域网设备。实时检测须在连接 ESP32 的电脑上启动本机服务。
获取实时 MVP 代码查看界面预览打开已启动的本机实验台

“打开本机实验台”仅在你已启动本机服务时可用。界面预览不连接设备，也不会产生人员判断。

在本机开始

  1. 复用已有 ESPectre 3.0.0 环境；将电脑和 ESP32 连到同一可互通局域网。
  2. 按仓库中的 启动说明配置已有私有模型和数据，运行 run.cmd 或 run.ps1。
  3. 输入设备当前 IP、实际地点和限时时长，点击“开始接入”；停止后检查流关闭与原模式恢复。
  4. 设备离线时可使用本机私有录制回放，并导出 CSV／JSON。

本次只公开代码、网页和说明。新原始录制、模型参数、设备元数据和私有日志留在本机。没有模型时实时页面保留“未知”。

已经实现的最小流程

功能行为
实时接入输入 IP，开始／停止；单次 3–600 秒，到时自动停止。
实验性判断显示 CSI 变化和当前判断；无数据、质量不足、范围不符或停止时保留未知。
清理与恢复不抢占其他原始流；检查会话关闭并尝试恢复接入前流量模式。
文件回放对本机记录运行同样的模型和运动对照，导出窗口结果。

当前限制也是实验结果

现有模型在历史无人场景中出现明显误报，尚不适合自动控制。一个无人、风扇开的录制中，237 个相互重叠的窗口全部被判为有人；这不是 237 次独立实验，也不能隐藏在一个总体准确率中。

2026-11-05 的软件检查覆盖模拟实时流、停止与恢复和浏览器断连。上次设备地址在只读探测中没有响应，本轮真实硬件接入与恢复尚未验证。静坐可靠性、抗风扇效果及跨房间能力仍需研究。
